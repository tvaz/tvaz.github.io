**Commissions**

If you are interested in a unique, handmade piece from me, I would love to chat!
Please send me an email with the following and we will see if we can work something out:
- Type of piece (Garment, plush etc)
- Link to a written pattern, video, or example inspiration photo of what you are looking for.
- Desired yarn color and material- if you are not sure, I can offer some recommendations based on the project.
- Budget
